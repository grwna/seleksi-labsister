# 2025-b-2 - Selection Part B, Stage 2

This folder contains the advanced technical projects for the final stage of Part B in the Lab Sister 2025 selection process. These tasks represent the pinnacle of system engineering, low-level programming, and blockchain architecture.

## 📁 Projects and Documentation

### 1. [Ngalegaan Kakawasan (Assembly x86-64 Web Server)](./1-Ngalegaan%20Kakawasan,%20Tamamo%20Silang%20-%20Sunda%20Priangan/)
- **Objective:** Develop a functional HTTP Web Server entirely in **x86-64 Assembly**.
- **Features:** 
  - Socket listening on specific ports.
  - Multi-process handling (forking) for concurrent requests.
  - Parsing HTTP Methods (GET, POST, PUT, DELETE).
  - Static file serving (HTML, images, MP4) and basic routing.
  - Integration with C binaries, 
  - Deployment on a VPS with Nginx as a reverse proxy
  - HTTPS support.

### 2. [Doki-Doki-Dokyumento (Specification Review)](./2-Doki-Doki-Dokyumento/)
- **Objective:** Critical analysis and rewriting of a complex technical specification document (IF2211 Strategic Algorithms). The goal of the review is to find flaws that makes the document hard to read, then fix the flaws to create a coherent and cohesive document.
- **Scope:** Correcting coherence, readability, and Indonesian grammar (EYD & Kata Baku) while ensuring the technical content remains accurate and actionable.

### 4. [Sybau Labubu Tracer (Network Simulation)](./4-Sybau%20Labubu%20Tracer/)
- **Objective:** Design a large-scale network topology simulating connectivity between 4 nations, implemented in Cisco Packet Tracer.
- **Network Stack:** 
  - Internal Routing: OSPF Multi-Area.
  - External Routing: BGP (Border Gateway Protocol).
  - Features: VLANs, Wireless Access Points, DNS/DHCP, NAT/PAT, SSH/Telnet, and full IPv6 implementation with tunneling.

### 5. [$BTC (Bitcoin Simulation)](./5-BTC/)
- **Objective:** Build a local Bitcoin-like network in **Python** to understand distributed consensus.
- **Components:** 
  - Block structure with SHA-256 hashing.
  - Mining with parameterized Proof-of-Work (PoW) difficulty.
  - Peer-to-peer synchronization using the "Longest Chain Rule."
  - Data persistence for node states.

### 6. [4-bit Fisherman (Computer Simulation)](./6-4-bit%20fisherman/)
- **Objective:** Simulate a **4-bit Computer Architecture** (CPU + Memory) using only basic logic gates in Logisim.
- **Capabilities:** Features an ALU for basic arithmetic (addition, subtraction, and multiplication), a 7-segment display for output, and memory storage for program results, all implemented using only logic gates and no built-in logisim components.

### 7. [Legacy Code Modernization (COBOL Banking)](./7-It’s%20Called%20‘Legacy%20Code’%20for%20a%20Reason/)
- **Objective:** Fix and modernize a broken legacy COBOL banking system.
- **Improvements:** Patching transaction logic, Dockerizing the application, and deploying on a Kubernetes (k3s) cluster.
- **Features:** Automated interest calculation service (every 23 seconds) and Rai Stone to IDR currency conversion.

### 8. [TTKI - Tulis Tulis Karya Imajinasi](./8-TTKI%20-%20Tulis%20Tulis%20Karya%20Imajinasi/)
- **Objective:** Write a creative short story to establish a narrative backdrop for the selection tasks.
