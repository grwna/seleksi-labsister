# stage-a - Initial Selection (Part A)

This folder contains the initial theoretical and fundamental tasks for the Lab Sister 2025 selection process.

## 📁 Selection Content

The first stage of the selection process focuses on fundamental concepts through theoretical tasks and essay questions. These tasks cover the various courses offered and managed by the laboratory:

- **Computer Organization:** Fundamentals of hardware architecture, processor design, and low-level programming.
- **Operating Systems:** Core concepts of kernel management, file systems, concurrency, and process scheduling.
- **Computer Networks:** Principles of data communication, network protocols, and the OSI model.
- **Parallel and Distributed Systems:** Theoretical foundations of concurrent execution and multi-node system synchronization.
- **Platform Technology:** Study of modern computing platforms, virtualization, and cloud infrastructure.
- **Integrated Systems Technology:** Design and implementation of complex, interconnected technological ecosystems.
- **Information Security:** Fundamentals of cryptography, system hardening, and defensive security measures.
