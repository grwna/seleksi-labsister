# Sisterlab Selection 2025 - Unified Repository

This repository is a consolidated collection of all projects and tasks submitted for the 2025 SEEI ITB Distributed Systems Laboratory assistant selection process.

Each stage's subdirectory contains a more detailed explanation of the projects, and most individual projects also have comprehensive documentation inside their respective directories.

>[!note]
>The comprehensive project documentations were primarily written in Bahasa Indonesia. While the stage's readme contains a more high-level summary of the projects in English.

## 📂 Selection Phases & Project List

### 🟦 [stage-a](./stage-a) - Initial Selection (Stage A)
Focuses on fundamental concepts, with tasks in the form of essay questions on various topics of the many courses offered by the lab. These courses are:
- Computer Organization 
- Operating Systems 
- Computer Networks
- Parallel and Distributed Systems
- Platform Technology
- Integrated Systems Technology
- Information Security


### 🟩 [stage-b-1](./stage-b-1) - Selection Stage B, Part 1
Technical tasks focused on systems administration, security, and parallel computing.
- **Manual Arch Linux Installation:** A professional step-by-step walkthrough for the installation of Arch Linux without automated scripts or installers.
    - ***Skills & Keywords***: Professional writing, OS Installation, Kernel-level configuration, Custom ISO packaging.

- **CTF Challenges:** A collection of CTF challenges covering Blockchain, Web, Forensics, Cryptography, and PWN.
    - ***Skills & Keywords***: Blockchain vulnerabity analysis, Web vulnerability patching, Digital Forensics, Penetration Testing, Post Quantum Cryptography, Reverse Engineering, PWN, CVSS Scoring.

- **DNS & Network Setup:** A 4-VM network infrastructure implementation featuring DNS servers, HTTP servers, and reverse proxies.
    - ***Skills & Keywords***: Network infrastructure design, Reverse proxy implementation, DHCP configuration, Firewall configuration.

- **Interactive Mandelbrot Generator** A high-performance Mandelbrot/Julia set generator using OpenMP (CPU) and CUDA (GPU) acceleration.
    - ***Skills & Keywords***: Parallel programming, GPU/Cuda Programming, Performance benchmarking, C++ GUI Implementation.  

- **Business Capability Modeling** Business Capability Model and technology stack analysis for an IT enterprise.
    - ***Skills & Keywords***: Enterprise Architecture, Business Capability Mapping, IT infrastructure strategy analysis

- **Integrated Systems Implementation:** Business documentation and secure API implementation using OAuth2.
    - ***Skills & Keywords***: Requirements engineering, Requirement's diagram design, Application architecture, API documentation.

- **Bitwise Big Number Multiplier** A big integer multiplier using Number Theoretic Transform (NTT) for calculation of upto $10^{1,000,000}$ digits, implemented using bitwise operators and primitive instructions only.
    - ***Skills & Keywords***: Bitwise programming, High precision arithmetic, Number Theoretic Transform, Discrete Convolution.

### 🟥 [stage-b-2](./stage-b-2) - Selection Stage B, Part 2
Advanced technical implementations and systems engineering.

- **Assembly x86-64 Web Server:** A high-performance web server written entirely in x86-64 Assembly, supporting forking, routing, and various MIME types.
    - ***Skills & Keywords***: Assembly programming, Socket programming, Process management, Binary linking/Syscalls

- **Document Review:** A project's technical specification review and revision, to create a more readable specification document.
    - ***Skills & Keywords***: Technical writing and editing, Document readability analysis, Linguistic auditing

- **Topology Design in Packet Tracer:** A complex simulation of a 4-country network topology using Cisco Packet Tracer. 
    - ***Skills & Keywords***: Network topology configuration, OSPF and BGP routing, VLAN trunking, IPv6 Tunneling, ACL configuration NAT/PAT overload

- **$BTC (Bitcoin Simulation):** A functional Blockchain network simulation in Python featuring mining, consensus, and a CLI client.
    - ***Skills & Keywords***: Blockchain architecture design, Cryptographic hasing, Proof-of-work consensus, P2P networking

- **4-bit Computer:** A complete 4-bit computer architecture using only logic gates simulated in Logisim.
    - ***Skills & Keywords***: Computer Architecture design, Arithmetic Logic Unit implementation, Memory address simulation, 7-segment display logic

- **Legacy Code (COBOL):** Modernization and fixing of a previously broken COBOL banking system, deployed using Docker and Kubernetes (k3s).
    - ***Skills & Keywords***: Legacy system modernization, Containerization and Orchestration, Reverse proxy deployment

- **Creative Writing:** A lore-based short story centered around the "S.I.S.T.E.R" entity.
    - ***Skills & Keywords***: Creative narrative writing
