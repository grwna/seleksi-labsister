# BCM - Baka!! Chuunibyou Mode

This directory contains the documentation for the **Business Capability Model (BCM)** task of the Lab Sister 2025 selection process.

## 📝 Task Description
The objective of this task is to develop a comprehensive **Business Capability Model** for a local IT enterprise. This involves analyzing the operational needs of a business and identifying the technological infrastructure required to execute its core processes.

## 📁 Contents
- **`13523035_BCM.pdf`**: The core deliverable containing the BCM diagram and the corresponding technological analysis.

## 🎯 Objectives
- Understand the corporate infrastructure and architectural layers of an IT company.
- Gain familiarity with Enterprise Architecture (AE) principles.
- Develop strategic planning skills for technological implementation within a business context.

## 🔗 References
This model follows principles found in frameworks like TOGAF and leanIX for modeling business capabilities.

- [TOGAF ArchiMate Capability Mapping](https://guides.visual-paradigm.com/understanding-and-creating-an-archimate-capability-map-in-togaf/)
